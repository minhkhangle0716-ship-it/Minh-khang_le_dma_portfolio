Montage

As the first project in Art 74, we learned how to use Premiere Pro to create a montage without audio. For my montage I made the story follow a boy's stages of life experiencing the joy of the beach, and eventually sharing this joy with his daughter. In this project I learned how to use transition effects and Lumetri color filters to create a cohesive story and aesthetic. I also learned how to use keyframes to create smooth transitions between clips, and how to adjust the timing of clips to create a rhythm that matches the mood of the story. Overall, I enjoyed this project because it allowed me to think about how I can tell a story using the "show don't tell" rule.
